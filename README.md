# Skyline — студия винила

Адаптивный сайт для Skyline в Энгельсе с интерактивной 3D-моделью BMW M2 CS 2026.

## Что сделано
- Автоматическое вращение самой 3D-модели вокруг вертикальной оси (примерно один оборот за 28,6 секунды).
- Вращение модели можно поставить на паузу и возобновить кнопкой «ПАУЗА / ВРАЩАТЬ».
- Ручное вращение мышью или пальцем, приближение, отдаление, поворот кнопками и сброс положения.
- Прозрачный WebGL canvas: у автомобиля нет отдельной прямоугольной подложки, он визуально сливается с тёмным фоном hero-секции.
- Разделы сайта соответствуют информации карточки 2ГИС: нанесение плёнки, перетяжка салона, шумоизоляция салона, EVA-коврики и аксессуары, способы оплаты и контакты.
- Реальные адрес и ссылки на отзывы/фотографии 2ГИС.
- Форма подготавливает сообщение и открывает WhatsApp студии. Пользователь сам подтверждает отправку.
- Адаптивная мобильная версия.

## Запуск
Откройте папку проекта в VS Code и запустите `index.html` через Live Server.
Или в терминале из этой папки выполните:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Не открывайте HTML двойным кликом: загрузка GLB через `fetch()` требует локального HTTP-сервера.

## Производительность
- Новая модель: исходный GLB 14,03 МБ; оптимизированный GLB 9,33 МБ; gzip-передача около 5,71 МБ.
- Ограничение devicePixelRatio: 1.5 на компьютерах и 1.25 на телефонах.
- Отключены дорогие real-time тени.
- Рендер останавливается, когда 3D-блок не виден или вкладка браузера скрыта.
- При автоматическом вращении меняется только поворот модели; OrbitControls не крутит камеру сам по себе.

## Максимальная оптимизация BMW M2 CS (ноябрь 2026)

Исходный GLB: **14.03 МБ**.
Оптимизированный GLB: **9.58 МБ**.
Файл для сайта (GZIP): **5.79 МБ**.

Что сделано без удаления видимых деталей:
- Все 39 index-буферов переведены с 32-битных на 16-битные индексы (все вершины укладываются в диапазон 16-bit).
- 39 наборов нормалей и 17 наборов tangent сжаты до normalized int16.
- 27 наборов UV-координат в диапазоне 0..1 сжаты до normalized uint16; UV с отрицательными и tiled-значениями сохранены без изменения.
- RGB-карты цвета/свечения переведены в высококачественный JPEG там, где это уменьшало размер.
- Одна карта свечения 1024px уменьшена до 512px; normal/roughness/metalness/data maps оставлены без потерь.
- В GLB добавлено расширение KHR_mesh_quantization.
- GZIP сжатие уровня 9 для передачи модели в браузер.

Проверки:
- GLB заголовок, размеры bufferViews и accessors проверены.
- Все 33 встроенные текстуры успешно декодируются.
- Модель повторно загружается через trimesh: 39 геометрий, 275 844 треугольника.
- Сайт распаковывает gzip-поток напрямую, без промежуточной копии сжатого файла.
- На мобильных устройствах ограничен pixel ratio до 1.0 для снижения нагрузки на GPU.

**Важно:** модель опубликована автором под CC BY-NC-SA 4.0. Лицензия запрещает коммерческое использование без отдельного разрешения правообладателя. Перед публикацией коммерческого сайта Skyline необходимо получить разрешение автора или использовать модель с коммерческой лицензией.


## Финальная оптимизация геометрии

Последняя сборка использует KHR_mesh_quantization для всех трёхмерных позиций:
- 39 наборов POSITION переведены во normalized uint16 с индивидуальным decode-transform на узлах.
- Нормали и tangent скорректированы с учётом обратного преобразования scale, затем сохранены в normalized int16.
- Индексы всех 39 мешей — uint16.
- 27 UV-наборов с диапазоном 0..1 — normalized uint16; UV с tiling/отрицательными значениями сохранены как float.
- Число треугольников оставлено без сокращения: **275,844**. Геометрия не упрощалась, чтобы не потерять детали кузова и оптики.

Точность реконструкции по исходной геометрии:
- максимальная ошибка позиции: **0.00003515** в локальных единицах исходной модели;
- максимальная угловая ошибка нормали: **0.0450°**;
- максимальная угловая ошибка tangent: **0.0275°**.

Финальный файл: **8.45 МБ GLB** / **5.24 МБ GZIP**.
