# SKYLINE — студия винила

Обновлённый адаптивный сайт студии Skyline в Энгельсе.

## Что входит
- Тёмный первый экран с фотографией реальной работы студии и синими акцентами.
- Адаптивная навигация для компьютеров и телефонов.
- Раздел услуг: виниловая оклейка, тонировка и плёнки, перетяжка салона, шумоизоляция, EVA-коврики и аксессуары.
- Два интерактивных сравнения «До / После»: BMW и Hyundai. Разделитель можно перетаскивать мышью, пальцем или клавиатурой.
- Форма заявки, которая собирает данные и открывает WhatsApp с подготовленным сообщением.
- Контакты, адрес и переход в 2ГИС.
- Лёгкая реализация на HTML, CSS и обычном JavaScript без Three.js, WebGL и 3D-моделей.

## Запуск локально
Откройте проект в VS Code и запустите index.html через Live Server. Также можно выполнить:

\`\`\`bash
python -m http.server 8000
\`\`\`

Затем откройте http://localhost:8000.

## Данные студии
Контакты и ссылки находятся в business-config.js. График работы не публикуется: перед визитом рекомендуется уточнить время по телефону.

## Фотографии
Фотографии сравнений предоставлены владельцем сайта и оптимизированы в WebP для быстрой загрузки.
